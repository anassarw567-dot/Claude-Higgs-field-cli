# Image Generation Prompts — "Engineers Knew" Disaster Documentary

One Midjourney/Higgsfield-style prompt per timestamp in the script. Every prompt ends in the same
locked style block so all 222 images feel like they belong to one continuous documentary.

**Style suffix (appended to every prompt):**
`cinematic true-crime documentary photograph, low-key chiaroscuro lighting, heavy dramatic shadows, teal and orange color grading, high contrast, muted desaturated background with one glowing element popping (fire, sparks, or a single light source), dramatic silhouette (no visible face), macro detail on evidence/documents/structure, hyperrealistic photographic or 3D-render quality, no blood, no gore, no bodies, no graphic violence, danger implied only through smoke, sparks, police tape, cracked concrete, or shattered glass, clean centered composition, no on-image text --ar 16:9`
